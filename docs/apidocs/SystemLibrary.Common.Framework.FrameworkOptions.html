SystemLibrary.Common.Framework

Configuration options for the framework's services and middleware pipeline

✕ 
var options = new FrameworkOptions
{
    UseHttpsRedirection = true,
    ViewLocations = new[] { "~/Folder/{0}/Index.cshtml" }
};

services.AddFrameworkServices(AppType.Web);
✕

Every option has a default, so only set the ones you want to change.

class FrameworkOptions

{

Additional assemblies whose controllers and views are registered with the application, default null

Assembly[] ApplicationParts
✕ 
options.ApplicationParts = new[] { typeof(AdminController).Assembly };
✕

The main assembly is always included. Use this for controllers in other projects or class libraries.

Cache-Control max-age in seconds for static file responses, default 604800 (7 days)

int StaticFilesClientCacheSeconds
✕ 
options.StaticFilesClientCacheSeconds = 3600; // 1 hour
✕

Requires UseStaticFilePolicy to be true. Has no effect if max-age is already set in the response.

Relative request paths from which static content is served, default null

string[] StaticRequestPaths
✕ 
options.StaticRequestPaths = new[] { "/static", "/public" };
✕

Requires UseStaticFilePolicy to be true.

Registers authentication services and middleware. Default: true.

bool UseAuthentication

Registers authorization services and middleware, default true

bool UseAuthorization

Registers Brotli response compression services and middleware, default false

bool UseBrotliResponseCompression
✕

If both Brotli and Gzip are enabled, the response uses whichever the client accepts, and the framework's provider order decides when both are accepted.

Creates a Data Protection key file valid for 100 years, so encrypted values and cookies can be read by every instance, default false

bool UseDataProtectionPolicy
✕ 
options.UseDataProtectionPolicy = true;
✕

Required for EncryptUsingKeyRing, DecryptUsingKeyRing and cookie encryption across instances.
The file is created in the parent folder of ApplicationInfo.RootPath.
All instances must use the same key file, so store it outside source control and deploy it with your pipeline.

Registers the developer exception page middleware, which shows detailed error information, default true

bool UseDeveloperPage
✕ 
options.UseDeveloperPage = false;
✕

Detailed errors can expose source code and internals, so set it to false for production unless the page is restricted elsewhere.

Registers forwarded headers middleware for proxy/load balancer support. Default: true.

bool UseForwardedHeaders

Registers Gzip response compression services and middleware. Default: true.

bool UseGzipResponseCompression

Registers HSTS middleware, which adds the Strict-Transport-Security header so browsers use HTTPS on later visits, default false

bool UseHsts
✕

Browsers ignore the header over plain HTTP, and ASP.NET Core skips it for localhost by default.

Registers HTTP to HTTPS redirection middleware. Default: false.

bool UseHttpsRedirection

Registers output cache services and middleware, default true

bool UseOutputCache

Registers response caching services and middleware. Default: true.

bool UseResponseCaching

Adds security middleware, default true

bool UseSecurityPolicy
✕ 
options.UseSecurityPolicy = false;
✕

In production only:

  • Adds nosniff for .js and .mjs files in the static branch
  • Adds Referrer-Policy: strict-origin-when-cross-origin on non-static and non-API requests
  • Adds a Content-Security-Policy that allows all content, but allows iframing only for the primary domain and its subdomains, on non-static and non-API requests

Other environments add no security headers, so all content and resources load freely.

Registers static file middleware serving from wwwroot and the auto-discovered folders public, static, dist, frontend, assets and files, default true

bool UseStaticFilePolicy
✕ 
options.UseStaticFilePolicy = true;
✕

Only GET and HEAD requests are served.
Serves unknown file types, enables HTTPS compression and appends Cache-Control if not already set.

Registers middleware that logs the status code, path and HTTP method of every response with a status of 300 or higher, default true

bool UseStatusCodeLogger
✕ 
options.UseStatusCodeLogger = false;

Custom view location expander for advanced Razor view resolution, default null

IViewLocationExpander ViewLocationExpander
✕ 
options.ViewLocationExpander = new MyViewLocationExpander();
✕

Use ViewLocations for simple path additions.

Custom Razor view location formats, added to the default search paths, default null

string[] ViewLocations
✕ 
options.ViewLocations = new[] { "~/Pages/{1}/{0}.cshtml" };
✕

{0} is the view name, {1} the controller name and {2} the area name.
