Cache

Static class for sharded in-memory caching with auto-generated cache keys, skip conditions, and optional fallback cache.
Default duration is 180 seconds.

  • Skip options: skipWhenAuthenticated (false), skipWhenAdmin (true), skipWhen (custom condition).
  • Pass null as cacheKey to always bypass cache. Pass "" to auto-generate from calling context.
✕

8 sharded containers, 60 000 items each by default, total of 480.000.
On compaction oldest 33% are evicted.
Null values are never cached. Auto-generated keys include namespace, method, scoped variables, IsAuthenticated and user roles.
Fallback cache requires a Pro license — returns last known good value on getItem failure or null result.
Admin roles: Admin, Admins, Administrator, Administrators, WebAdmins, CmsAdmins and lowercase variants.
