SystemLibrary.Common.Framework

A thread-safe dictionary split into 4 internal concurrent dictionaries (shards) to reduce contention

✕ 
var dict = new ShardedDictionary<string, int>(10000);
dict.Add("a", 1);
var value = dict["a"]; // 1
✕

Meant as a size-capped cache. When a shard exceeds its share of maxItemCount, the whole shard is cleared, so up to a quarter of the cached items disappear at once.
The shard is picked from the low 2 bits of the key's hash code.
Only Cache accepts a null key. The other methods throw ArgumentNullException for null.
