Extension methods for Type.

class TypeExtensions

{

Returns the default value of the type: a new instance for value types, otherwise null

static object Default(Type)

✕ 
typeof(int).Default();    // 0
typeof(int?).Default();   // null
typeof(string).Default(); // null
✕

Nullable value types, reference types and interfaces return null. Enums return the integer 0, not an enum value.

Returns the most meaningful name of the type: the first type argument for generics and collections, otherwise the type name

static string GetFriendlyName(Type)

✕ 
typeof(Car).GetTypeName();                              // "Car"
typeof(List<Car>).GetTypeName();                  // "Car"
typeof(Dictionary<string, Car>).GetTypeName();    // "String, Car"
✕

A dictionary returns "Key, Value" with both type names.

Returns the generic type argument at index, or null if there is none

static Type GetTypeArgument(Type, int)

✕ 
typeof(List<Car>).GetTypeArgument();  // typeof(Car)
typeof(Car[]).GetTypeArgument();            // typeof(Car)
✕

If the type has no generic arguments itself, the collection interfaces it implements are searched, so arrays work too.

Returns all generic type arguments of the type, or null if there are none

static Type[] GetTypeArguments(Type)

✕ 
typeof(Dictionary<string, Car>).GetTypeArguments(); // [ typeof(string), typeof(Car) ]
✕

If the type has no generic arguments itself, the collection interfaces it implements are searched.

Returns true if the type inherits from or implements type, and false if they are the same type

static bool Inherits(Type, Type)

✕ 
typeof(Car).Inherits(typeof(IVehicle)); // true
typeof(Car).Inherits(typeof(Car));      // false

Returns true if the type is a compiler-generated anonymous type

static bool IsAnonymousType(Type)

✕ 
var item = new { Name = "John" };
item.GetType().IsAnonymousType(); // true

Returns true if the type is a concrete class that can be instantiated

static bool IsClassType(Type)

✕ 
typeof(Car).IsClassType();    // true
typeof(string).IsClassType(); // false
typeof(ICar).IsClassType();   // false
✕

Abstract classes, interfaces, enums, arrays, dictionaries, tuples, delegates, string and StringBuilder return false.

Returns true if the type is a Dictionary<,>, IDictionary<,>, IDictionary or a generic type implementing IDictionary

static bool IsDictionary(Type)

✕ 
typeof(Dictionary<string, Car>).IsDictionary(); // true
typeof(List<Car>).IsDictionary();               // false
✕

A non-generic class that implements IDictionary, such as Hashtable, returns false.

Returns true if the type is internal and not nested

✕ 
typeof(InternalHelper).IsInternal(); // true when declared as: internal class InternalHelper

Returns true if the type is a KeyValuePair<,>

static bool IsKeyValuePair(Type)

✕ 
typeof(KeyValuePair<string, Car>).IsKeyValuePair(); // true

Returns true if the type is an array or a List<T>

static bool IsListOrArray(Type)

✕

typeof(Car[]).IsListOrArray();          // true
typeof(Car).IsListOrArray();            // false
✕

Other collections such as IList<T>, HashSet<T> and dictionaries return false.

✕

Returns true if the type is one of the built-in numeric types

static bool IsNumberType(Type)

✕

typeof(int?).IsNumberType(); // false
✕

int, uint, long, ulong, short, ushort, byte, sbyte, float, double and decimal. Nullable versions return false.

Sets a static property or field by name, including non-public members

static void SetStaticMember(Type, string, object)

✕ 
typeof(Settings).SetStaticMember("Counter", 5);
✕

Properties are checked before fields, non-public before public. Only members declared on the type itself are found, not inherited ones.
Does nothing if the type is null, and throws if no member with that name exists.
