SystemLibrary.Common.Framework.App

Application

Static class for starting, building and stopping the ASP.NET application host.

BaseApiController

Abstract base class for API controllers with automatic endpoint documentation and built-in response helpers. All controllers inheriting BaseApiController are automatically picked up if matching the request path.

Cache

Static class for sharded in-memory caching with auto-generated cache keys, skip conditions, and optional fallback cache.
Default duration is 180 seconds.

  • Skip options: skipWhenAuthenticated (false), skipWhenAdmin (true), skipWhen (custom condition).
  • Pass null as cacheKey to always bypass cache. Pass "" to auto-generate from calling context.
CalleeCancelledRequestException

Thrown when the caller cancels an in-flight request via a CancellationToken.

Client

Client is a class for all http(s) requests in your project

Uses HttpClient and Polly behind the scenes for features such as reusing tcp connections, retry on 502 and 504 status codes, and optionally a request breaker for 7 seconds, if 25 error codes (404, 429, 500, 502, 503, 504, 505) occurs in a row

useRetryPolicy: false, will retry once if request is a file request or GET or POST and status code is 502 or 504

Options:

useRetryPolicy:

True: same as 'false', but adds:

  • retries one additional time on 502, 504 GET, POST

- retries up to two times if response is null (timeout/no response)

  • retries once on 401 GET, POST

- retries once on 404 GET

  • retries once on 500 GET, POST

- retries once on 404, 500, 502 504 file request

  • retries once on OPTION, PATCH, HEAD, CONNECT, TRACE
ClientResponse

Base class for ClientResponse — use as return type when you want a concrete non-generic response type in your methods. Always contains a Data property (null if unset) — safe to serialize to JSON without undefined in JS.

ClientResponse<T>

The response that all Client methods returns

Note that a response statuscode might be 200 OK, but the IsSuccess might be false in scenarios where no response were returned

HtmlHelperFactory

Builds IHtmlHelper instances outside of a Razor view context.

OutputCachePolicy

Output cache policy names for use with the [OutputCache] attribute.

ServiceInstance

Static accessor for resolving services from the application's service provider.

IFrameworkHooks

Hooks into the application startup pipeline. All methods have default empty implementations.

AppHosting

Hosting server type used when starting the application via Application.Start or Application.Build.

AppType

Specifies whether the application serves web pages, API endpoints, or runs as a console process.

CacheDuration

Cache duration presets in seconds for use with Cache methods.

ContentType

Media types for Client request methods, sent as the Accept header.

Use "None" to omit the header entirely.
