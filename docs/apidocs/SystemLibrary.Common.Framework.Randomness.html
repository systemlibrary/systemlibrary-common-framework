SystemLibrary.Common.Framework

Static class for generating random values

✕

Only Bytes is cryptographically secure. All other methods use Random.Shared, so don't use them for tokens, passwords or keys.
All methods are thread safe.

class Randomness

{

Returns a byte array of the given length filled with cryptographically secure random bytes

static byte[] Bytes(int)

✕ 
var key = Randomness.Bytes(32);
✕

Safe to use to generate random tokens or keys.

Returns a random double from minValue up to, but not including, maxValue

static double Double(double, double)

✕ 
var a = Randomness.Double();         // 1 to 9999
var b = Randomness.Double(0.5, 1.5);

Returns a random integer from 0 to maxValue, both included

static int Int(int)

✕ 
var a = Randomness.Int();    // 0 to 1000
var b = Randomness.Int(10);  // 0 to 10
✕

For int.MaxValue the upper bound is excluded.

Returns a random integer from minValue to maxValue, both included

static int Int(int, int)

✕ 
var a = Randomness.Int(5, 10); // 5 to 10

Returns a random base62 string with a length from min to max, both included

static string String(int, int)

✕ 
var a = Randomness.String();       // 6 chars
var b = Randomness.String(8, 16);  // 8 to 16 chars
✕

Not secure, and not guaranteed unique.
Strings longer than 6144 chars repeat the same 6144-char block, so they are not random beyond that.
In tight loops of 10K+ calls, consider an ArrayPool implementation for lower memory overhead.

Returns random paragraph text cut to a length from minLen to maxLen

static string Words(int, int, int)

✕ 
var text = Randomness.Words();                // about 220 chars
var same = Randomness.Words(fixedSeed: 42);   // same text every call
✕

Built from sentence parts and ends with a period.
A fixedSeed of 0 or more returns the same text each time, as long as minLen equals maxLen. -1 means random.

Clears the StringBuilder, fills it with random paragraph text and returns it

static StringBuilder Words(StringBuilder, int, int, int)

✕ 
var sb = new StringBuilder();
Randomness.Words(sb, 500, 1000);
✕

Same rules as the string overload. Reusing a StringBuilder avoids allocating a new one per call.

}
