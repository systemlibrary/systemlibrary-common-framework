Installation

🧩 Requirements

  • .NET 10 or later

🚀 First time setup

  1. Create a new .NET 10 project
    (for example: ASP.NET Core Empty)

  2. Add NuGet package:

dotnet add package SystemLibrary.Common.Framework
  1. Add ~/Properties/launchSettings.json
{
  "$schema": "http://json.schemastore.org/launchsettings.json",
  "profiles": {
    "Kestrel": {
      "commandName": "Project",
      "dotnetRunMessages": false,
      "launchBrowser": true,
      "applicationUrl": "http://localhost:5010;https://localhost:5011",
      "environmentVariables": {
        "ASPNETCORE_ENVIRONMENT": "Development"
      }
    }
  }
}
  1. Add ~/appsettings.json:
{
  "systemLibraryCommonFramework": {
    "app": {
      "name": "company_unique_appname"
    }
  }
}
  1. Modify ~/Program.cs:
using SystemLibrary.Common.Framework.App;

Application.Start();

  1. Run the application.

  2. Visit the application, all url's should show a 404 as you have an empty web application.
