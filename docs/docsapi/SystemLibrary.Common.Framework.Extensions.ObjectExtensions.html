ObjectExtensions

Extension methods for objects.

class ObjectExtensions

{

Converts an object array of integers or strings to a typed enum array.

static TEnum[] AsEnumArray<TEnum>(object[])

✕ 
new object[] { 1, 2, 3 }.AsEnumArray<Colors>();       // by int index
new object[] { "Red", "Black" }.AsEnumArray<Colors>(); // by key name
✕

Only supports int and string arrays — throws for any other element type.
Assumes all elements in the array are the same type.

Serializes the object to a JSON string.
If the input is already a valid JSON string, it is returned as-is.

static string Json(object, bool)

✕ 
var json = user.Json(camelCase: true);  // { "firstName": "Hello World" }
var json = user.Json(camelCase: false); // { "FirstName": "Hello World" }
✕

Enums with an EnumValue attribute serialize as the attribute value, not the key name.

Serializes the object to a JSON string with optional custom converters and serializer options.

static string Json(object, JsonSerializerOptions, bool, params JsonConverter[])

✕ 
var json = user.Json();
var json = user.Json(new CustomConverter());
var json = user.Json(translateUnicodeCodepoints: true);
✕

Enums with an EnumValue attribute serialize as the attribute value, not the key name.

Serializes the object to a JSON string with one or more custom converters.

static string Json(object, params JsonConverter[])

✕ 
var json = user.Json(new CustomConverter());

Returns a sanitized text representation of the object's public properties in the specified format.

static string ToSanitizedObjectText(object, ObjectSanitizedFormat, ObjectSanitizedFormatOptions)

✕

Only supports class types — throws NotSupportedException for value types.

Serializes the object to an XML string.

static string Xml(object)

✕ 
var xml = user.Xml();
}
