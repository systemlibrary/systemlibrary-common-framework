SystemLibrary.Common.Framework.Attributes

ConfigDecryptAttribute

Marks a property as the target for a decrypted config value. The named source property is decrypted once at startup and written into the decorated property. Values must be encrypted using the parameterless string.Encrypt().

EnumTextAttribute

Assigns a display text to an enum field, used in serialization and string conversion. Falls back to the enum key name when not applied.

EnumValueAttribute

Assigns a custom value to an enum field, used in serialization and string conversion. Falls back to the enum key name when not applied.

JsonCompressAttribute

Compresses and decompresses a property or field on JSON serialization and deserialization. Useful for minimizing large string or obfuscate numeric values sent to or received from clients.

JsonEncryptAttribute

Encrypts and decrypts a property or field on JSON serialization and deserialization using the framework encryption key. Useful for hiding sensitive values in API responses — encrypted client-side values are transparently decrypted before reaching your controller.

JsonObfuscateAttribute

Obfuscates and deobfuscates a property or field on JSON serialization and deserialization. Hides int IDs and similar values from API responses, preventing enumeration attacks against endpoints accepting integer identifiers.
