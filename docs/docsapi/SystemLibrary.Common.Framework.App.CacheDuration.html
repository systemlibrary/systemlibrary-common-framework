CacheDuration

Cache duration presets in seconds for use with Cache methods.

enum CacheDuration

{

2 hours for data weekly changing data or large and expensive data

  L = 7200

20 minutes for moderate-refresh data

  M = 1200

3 minutes for frequent refreshes

  S = 180

Uses the default duration from appsettings, falling back to S (180s) if unset.

  Unset = 0

1 day for data that changes, theres no harm in just showing it the next day

  XL = 86400

20 seconds for real-time, low-latency needs

  XS = 20

2 weeks for static data

  XXL = 1209600
}
