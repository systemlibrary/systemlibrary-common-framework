ContentType

Media types for Client request methods, sent as the Accept header.

Use "None" to omit the header entirely.

✕ 
var client = new Client();
var response = client.Post<string>("https://systemlibrary.com/post", data, ContentType.text);
✕

Not all types have dedicated serialization handling — unrecognized types are sent as-is.
