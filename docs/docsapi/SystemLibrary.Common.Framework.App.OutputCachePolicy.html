OutputCachePolicy

Output cache policy names for use with the [OutputCache] attribute.

✕

Eviction is simple, fast and completely resets on a per policy:

// Example evicting CacheAuthenticated
await cacheStore.EvictByTagAsync(OutputCachePolicy.CacheAuthenticated, default);
