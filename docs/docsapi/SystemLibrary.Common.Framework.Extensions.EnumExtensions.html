EnumExtensions

Extension methods for enum values.

class EnumExtensions

{

Returns the EnumText attribute value, or null if not applied.

static string GetEnumText(Enum)

✕ 
enum Color { [EnumText("White")] Black, Pink }

Color.Black.GetEnumText(); // "White"
Color.Pink.GetEnumText();  // null

Returns the EnumValue attribute value as object, or null if not applied.

static object GetEnumValue(Enum)

✕ 
enum Color { [EnumValue(1234)] Black, [EnumValue(null)] Blue, Pink }

Color.Black.GetEnumValue(); // 1234 as int
Color.Blue.GetEnumValue();  // null
Color.Pink.GetEnumValue();  // null

Returns true if the enum value matches any of the provided values.

static bool IsAny(Enum, params Enum[])

✕ 
Color.Red.IsAny(Color.Black, Color.Blue); // false
Color.Red.IsAny(Color.Red, Color.Blue);   // true

static T ToEnum<T>(Enum)

Returns the EnumText attribute value, or the enum key name if not applied.

static string ToText(Enum)

✕ 
enum Color { [EnumText("White")] Black, Pink }

Color.Black.ToText(); // "White"
Color.Pink.ToText();  // "Pink"

Returns the EnumValue attribute value as string, or the enum key name if not applied.
Enum keys prefixed with _ followed by digits have the underscore stripped automatically.

static string ToValue(Enum)

✕ 
enum Color { [EnumValue(1234)] Black, [EnumValue(null)] Blue, Pink }

Color.Black.ToValue(); // "1234"
Color.Blue.ToValue();  // null
Color.Pink.ToValue();  // "Pink"
}
